# Dependencias de terceros

## PdfSharpCore y MigraDocCore.Rendering

- Versiones utilizadas: `1.3.67`.
- Uso: generación de documentos PDF de cotización A4 desde el servidor.
- Licencia: MIT, según `LICENSE.md` de [PdfSharpCore](https://github.com/ststeiger/PdfSharpCore).
- El proyecto incluye estas bibliotecas como paquetes NuGet y no modifica su código fuente.

Revisa las licencias y avisos de las dependencias transitivas antes de redistribuir o desplegar el sistema en una organización.

- Licencia: MIT, según el repositorio [ClosedXML](https://github.com/ClosedXML/ClosedXML).
