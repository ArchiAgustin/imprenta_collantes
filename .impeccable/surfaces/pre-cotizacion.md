# Pre-cotización asistida

- Target: `ProyectoFinal/Views/PreCotizacion/Index.cshtml`
- Mode: Operate; existing Collantes working-sheet visual world.
- User: Admin or seller with permission to create quotes.
- Task: prepare an anonymized request, explicitly review what leaves the system, inspect structured suggestions, match real products, then transfer to the ordinary quote editor.

## Direction contract

**THESIS:** A visible privacy checkpoint before analysis, not a chat that silently sends customer data or saves a quote.

**OWN-WORLD:** Same paper, ink, restrained teal action, rules and compact form conventions as the quotation editor.

**STORY:** Paste → review redacted text → explicitly approve remote call → inspect proposed lines → select catalogue entries → transfer editable draft. Manual quote remains reachable throughout.

**FIRST VIEWPORT:** Plain heading, short privacy warning and large request field with one prepare action. Subsequent states place the exact outbound text ahead of the call button, then a readable row-by-row checklist with unresolved matches visible.

**FORM:** A three-state server-rendered form, not a conversation transcript. No saved AI output, hidden customer match or invented prices.

**FINISH:** HTTP tests of permissions, redaction, explicit approval, catalogue transfer and manual quote save; fake HTTP provider tests of strict schema, timeout and missing key. Responsive stylesheet reviewed at desktop/mobile widths. No external credentials or unreviewed user text in provider requests. A live Groq call requires the environment owner to supply a private API key.
